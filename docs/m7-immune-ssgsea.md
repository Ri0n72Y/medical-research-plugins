# M7 — Public immune marker ssGSEA in Python

This stage implements **single-sample gene set enrichment**, not deconvolution. It provides a practical public alternative for an AI Harness research demonstration of the CAPN1 / AML paper without R, missing licensed CIBERSORT data or clinical inference.

## Reproducibility

Input: `study/processed.json` with SHA-256 verified `tpm-unstranded.tsv`, `gene-annotation.tsv`, and the compatible `study/survival.json` paired case/file/group `cohort.tsv`. **Use TPM from M2, never M4 DEG-selected genes.**

The reference is a *content-pinned immutable download* of Enrichr's `PanglaoDB_Augmented_2021` gene set library (GMT). The date in the library name is **not** a guarantee of static content: each retrieved snapshot stores its exact bytes, source URL, hash and retrieval time. Candidate signatures are selected by a predeclared immune-cell-name regex; the rule is an engineering demonstration, not a clinical classifier. Marker-signature origin may span heterogeneous tissues/species; do not infer AML infiltration fractions.

Scientific implementation uses Python `gseapy==1.3.0` with `gp.ssgsea`, `sample_norm_method='rank'`, `correl_norm_type='rank'`, `weight=0.25`, `permutation_num=0`, `threads=1`, `min_size=5`, `max_size=500`, seed 42. Raw GSEApy ES and NES are saved. Exploratory high/low score comparisons use SciPy two-sided Mann–Whitney and Statsmodels BH. These are associations, not causation or evidence of immune-cell abundance.

References:
- https://gseapy.readthedocs.io/en/latest/gseapy_example.html
- https://maayanlab.cloud/Enrichr/

## Run

D5 in the study template is unresolved. Do not treat its proposed ssGSEA-only default as a decision.

```sh
python -m pip install -r requirements.txt
pnpm run immune --workspace /absolute/path/to/research-workspace --immune-mode ssgsea-only
```

The explicit CLI mode is a documented run-level choice. Alternatively record `D5.status: selected` and `D5.selected: ssgsea-only` in the study's decision YAML. If choosing CIBERSORT or another public substitute, this narrow implementation fails explicitly rather than inventing a result or substituting methods.

The analysis stores `gene-mapping.tsv`, `signature-coverage.tsv`, `immune-scores.tsv`, `group-comparison.tsv`, `immune-signatures.svg`, `runtime.tsv`, `statistics.json` and `report.md` under `runs/m7-immune/`, with SHA-256 output manifests. `study/immune.json` is updated only after a completed run. Repeating a compatible run uses cache; damaged/incompatible completed results fail closed unless the user explicitly requests `--refresh-signatures`.

## Boundaries

GSEApy ssGSEA differs from R GSVA/ssGSEA in implementation and may differ numerically. The original paper's exact signatures and parameters are not guaranteed. Scores are not immune cell proportions, the group p-values are exploratory, and there is no biological mechanism or clinical treatment conclusion. No M8 full report is generated by this stage.
